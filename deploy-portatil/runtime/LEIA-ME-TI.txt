========================================================================
 SISTEMA DE QUALIDADE (SQE) - INSTALACAO NO SERVIDOR (para o TI)
========================================================================

O QUE E:
  Sistema web interno, acessado pelo navegador na rede da empresa.
  Nao instala nada no Windows. Tudo (banco de dados e sistema) roda de
  dentro desta pasta. Os usuarios NAO instalam nada nas maquinas deles.

------------------------------------------------------------------------
 PASSO A PASSO (leva ~2 minutos)
------------------------------------------------------------------------
  1) Copie esta pasta inteira para o servidor
     (ex.: C:\Qualidade-SQE).

  2) Clique com o botao direito no arquivo  INSTALAR.bat
     e escolha "Executar como administrador".

  3) Aguarde a mensagem "TUDO PRONTO!" - ela mostra o endereco de acesso.

  4) Informe ao solicitante o IP FIXO do servidor.
     Os usuarios vao acessar assim:   http://IP-DO-SERVIDOR:8090

  Pronto. O sistema sobe sozinho a cada reinicio do servidor.
  Ninguem precisa dar "start" manual no dia a dia.

------------------------------------------------------------------------
 O QUE O INSTALAR.bat FAZ (sem instalar nada no Windows)
------------------------------------------------------------------------
  - Cria uma TAREFA AGENDADA que sobe o sistema quando o servidor liga.
  - Cria uma regra de FIREWALL liberando as portas 8090-8100 apenas na
    rede interna (perfil dominio/privada). O banco NAO fica exposto.
  - Configura um BACKUP DIARIO automatico (20:00) na subpasta "backups".
  - Sobe o sistema imediatamente.

------------------------------------------------------------------------
 REQUISITOS NO SERVIDOR
------------------------------------------------------------------------
  - Windows (Server 2016/2019/2022 ou Windows 10/11).
  - Permitir executar programas desta pasta (caso haja AppLocker/politica
    de restricao, liberar a pasta C:\Qualidade-SQE).
  - Caso haja antivirus corporativo agressivo, adicionar a pasta as
    excecoes (evita que arquivos sejam bloqueados).
  - Recomendado IP FIXO no servidor.

------------------------------------------------------------------------
 COMANDOS UTEIS (raramente necessarios)
------------------------------------------------------------------------
  start.bat   -> liga o sistema manualmente
  parar.bat   -> desliga o sistema
  backup.bat  -> gera um backup do banco na hora

  A porta em uso fica registrada em:  config\porta.txt
  Logs ficam na pasta:                logs\

------------------------------------------------------------------------
 SE ALGO DER ERRADO
------------------------------------------------------------------------
  - "Nao consigo acessar de outro PC": confirme o IP do servidor e se a
    regra de firewall foi criada (a porta pode ter mudado para 8091, 8092...
    veja config\porta.txt e ajuste o endereco).
  - "Nada abre": rode start.bat manualmente e veja as mensagens; confira
    tambem logs\backend.log e logs\pg.log.
  - Bloqueio por politica/antivirus: liberar a pasta e rodar de novo.

  Dados ficam na pasta "dados". Backup fica na pasta "backups".
  Para mover os backups para uma pasta de rede, edite o backup.bat
  (linha "set DESTINO=...").
